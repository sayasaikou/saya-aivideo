## 一、这一轮真正解决的问题：内存墙（已结）

**现象**：s4 / s5 第四轮全部 OOM，产物目录里只剩 `job.json`。

**根因（实测，不是推断）**：**文本编码器档位选错**。
- 原用 `Qwen3-VL-32B-Instruct-layer50_quanto_bf16_int8.safetensors` = **24.89 GB**
- 本机早就躺着 `qwen3vl_32b_minimax_h3_nvfp4_awq.safetensors` = **14.61 GB**（10-08 下的，从没跑过）
- 账：权重 19.61 + 编码器 24.89 = **44.5 GB > 31.7 GB 物理内存**；换档后 = **34.2 GB**，能挤下

**换档怎么落地（可复现）**：
```
WanGP 的 CLI **不认** UI 那种 variant id ⇒ 报 `Unknown model type: variant::…`
正解：在 $env:DSH_AI\Wan2GP\defaults\ 下加一个自定义模型定义：
    "architecture": "minimax_h3_ref2va_pruned",
    "text_encoder_variant": "nvfp4_awq"
文件：defaults\minimax_h3_ref2va_pruned_nvfp4.json（新增，原文件一字未动）
job 里的 model_type 改指这个名字即可
```
**实测收益**（97 帧冒烟，同一提示词）：

| 指标 | int8 | nvfp4 | 变化 |
| --- | --- | --- | --- |
| 页面文件峰值 | 16.2 GB（> 14 GB 上限 ⇒ 提交失败被杀） | **7.29 GB** | −55% |
| 磁盘队列峰值 | 48 | **5** | −90% |
| %DiskTime 峰值 | 1554% | 329% | −79% |
| 内存空闲最低 | 逼近 0（颠簸） | **6.0 GB** | 有底 |

**192 帧全量实测**：s4 = 8 分 20 秒 / 11.95 MB；s5 = 8 分 24 秒 / 12.50 MB；s4-f（提示词 7014 字符）= 9 分 28 秒 / 10.48 MB。**帧间自检 outliers=none 或单点**。

> ⚠️ 顺带更正一条旧结论：本轮之前档案里写的「提示词越长 ⇒ 编码越久 ⇒ 换页越狠 ⇒ OOM」**方向对但不是主因**。真正一击见效的是**换编码器档位**；提示词长度只是压垮的最后一根稻草。

### 2. 手部动作 —— 模型没有"解剖学模型"，只有"视觉先验"
- 实测现象：让它"翻手"，它**把手的正反面整体替换**（手背渲染成手心），而不是"绕轴翻转"。
- 推论（本轮归纳，供下一位验证）：**凡是"沿某个轴旋转"的动作（翻手/翻腕/转身/扭头），模型倾向于用"换一个看起来对的视图"来实现，而不是真的转动。**
- ⇒ 对策方向：**别要求旋转动作**，改成"结果状态"（直接给"手心朝上"的末态）；或者用**首尾帧/首帧锚定**把姿态交给画面而不是文字。

### 3. 提示词写法：叙述 ⇒ 渐变；时间码 ⇒ 顿挫
- 实测：写成连续叙述（"火焰缓慢推进……"）⇒ 出来一条**平滑的暖→冷渐变**；
- 改成**带时间码的四拍 + 明确"停顿"这一拍**（0-2.5 / 2.5-4 / 4-5.5 / 5.5-8）⇒ 至少节奏被拆开了（本轮未最终验收，但**顿挫这件事必须靠"谁先停、谁后动"来写**，不能只写"颜色变化"）。
- ⇒ 判据：**因果链在提示词里必须落成"时间块 + 各自的状态变化"，不能写成一个 continuous 的动词串。**

### 4. 空间描述要"可渲染"，不要"相对方位"
- 反例（本轮原文）：`by its upper-left corner between her thumb and forefinger` —— 没写哪只手、几根指头、照片朝哪 ⇒ 模型自己编一个。
- 正解方向：**不写"哪只手"这种解剖学称谓，只写物理动作**（"拇指压正面、食指中指在后面托、其余蜷起不碰、纸向下垂"），并叠**禁令**（只许一张纸/一只手/画面里不许出现第二张脸）。

### 5. 工具链上的两个硬坑（都实测踩过）
- 🔴 **用 PowerShell 写 job.json 会带 UTF-8 BOM** ⇒ WanGP 的 `json.load` 直接拒收（`Invalid JSON: Unexpected UTF-8 BOM`，秒退）。必须 `[System.IO.File]::WriteAllText(path, json, (New-Object System.Text.UTF8Encoding($false)))`。
- 🔴 **提权/计划任务脚本必须纯 ASCII**：PS 5.1 按 ANSI 读 `.ps1`，中文注释会炸成 `Missing expression after ','`。
