# 一场五镜短片的失败诊断：症状、根因、改法

> 场景：参考图驱动的图生视频，五镜拼装，角色与场景由参考图锁定。
> 本文是一张**验收后的诊断表**：每条都从可见症状倒推到生成机制，再给改法。
>
> 分档：标「实测」的项在重跑后有可复核的指标或产物；标「现场记录」的项是真实发生但触发条件未完全复现。

## 一、通病表

| 症状 | 根因判断 | 改法 | 分档 |
| --- | --- | --- | --- |
| 首帧残留 ≥0.2 s 的旧画面 | `image_start` 是**起始条件**而不是「第 0 帧」：模型把它当参考锚，前几帧在消化它 | 成片后直接裁掉前 0.2–0.3 s；或让首帧图就是目标视频的第 0 帧 | 实测 |
| 透视/构图不可能，肢体像被扭过 | 模型在「**展示**」道具：为了让照片内容朝向镜头，把手和身体扭成现实中不存在的角度 | 不再要求「道具朝向镜头」：改成「朝她自己」「镜头在肩后俯视」，或干脆不露正面 | 现场记录 |
| 背景每一镜都不一样，且过于简陋 | ① 参考图是白底立绘 ⇒ 场景全靠模型即兴编；② 每镜重述场景时措辞不同；③ 模型对「富丽室内」的先验弱 | ① 锁一张房间母版（所有镜共用首帧锚，或深度图 + ControlNet）；② 场景描写逐字固定；③ 给可数物件清单 | 现场记录 |
| 火太小、没有冲击力 | 提示词里写的是 `small` / `a small warm amber fire` —— 是写法把火的体积限制住了 | 按画面占比描述（约手掌的 1.5–2 倍），起势写在几个帧内完成 | 实测 |
| 叙事节奏平 | 提示词全是 `steadily` / `slowly` / `then` 这类匀速词，等于告诉模型「慢慢来」 | 每镜只给一个节拍，写清这一拍在几秒内完成；关键动作使用瞬时词 | 实测 |
| 手指穿过照片（穿模） | 空间关系没写清：哪根手指在纸前、哪根在后 | 写物理动作而不是解剖学称谓（「拇指压正面、食指中指在后面托」），并叠「只许一张纸」的禁令 | 现场记录 |
| 照片只是套了一层火焰特效，没真的被烧 | 「燃烧」被写成了光效叠加，而不是材质变化 | 写成**发生在纸的内部**：变黑、卷曲、破裂；灰有「掉出画面」的动作 | 实测 |
| 火从捏着的那一角起烧（物理上不可能） | 模型不懂「手里捏着的角必须是最后剩下的那一个」 | 明确火从**对角**开始，向手指推进，在离手指一步之遥处停下 | 现场记录 |
| 一个镜头里把完整过程塞完：烧断 → 外圈掉落 → 粉末 → 手摊开 | 违反了「一镜一事」：单镜可用生成预算有限，阶段越多越容易失控 | 拆成三镜：烧尽 / 灰落 / 摊掌；每镜只做一件事 | 实测 |

## 二、三条可直接复用的判据

### 1. 冲击力来自时间反差，不是体积

一个 3 秒匀速升起的大火，看起来就是「慢慢烧起来」；同样体积的火，如果写成「三个帧内到满、半秒内回落三分之一、之后纹丝不动」，看起来才是「窜出来的」。

禁用的词：`small` / `slowly rises` / `steadily` / `grows gradually`。

可直接套的模板：

```
The fire arrives in a jolt, not a growth:
- strike: it is at full size in three or four frames;
- settle: it drops back to about two thirds of that peak within half a second;
- hold: for the rest of the shot it stays exactly at that level.
```

### 2. 旋转动作一律改写成末态

「翻手」「翻腕」「转身」这类沿轴旋转的动作，模型会直接**换一个看起来对的视图**（手背渲染成手心），而不是真的转动。

实测：改成只写末态（「手心朝上，指间有一层灰」）之后，姿态对了。

### 3. 一镜一事可以用帧间差量化验收

拆镜前后用同一套抽帧自检：一镜一事的镜头帧间中位差明显更低、突变点更少。这是判断「是不是又把多件事塞进一个镜头」的客观依据，比目测可靠。

## 三、根因归类（换项目也适用）

| 根因 | 表现 | 修法 |
| --- | --- | --- |
| 参考图信息缺口 | 白底立绘 → 场景全靠编 | 补场景母版；或用深度图锁空间 |
| 每镜重新描述 | 同一房间每镜长得不一样 | 不变量逐字固定；只改动作与景别 |
| 用形容词代替物理 | 火小、节奏平、纸没真烧 | 写尺寸比例、时间点、材质变化 |
| 要模型做它没有的动作模型 | 旋转、多阶段过程 | 改写末态；拆镜 |
| 空间关系含糊 | 穿模、道具漂移 | 写可渲染的物理动作；点名关键道具 |

> 一个容易被忽略的点：**上述症状里有一半不是模型能力问题，是提示词把过程写成了结果、把结果写成了形容词。** 先改写法，再考虑换模型或加 LoRA。
