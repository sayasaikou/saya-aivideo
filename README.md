# saya-aivideo

本地视频生成（图/参考图 → 视频 → 拼接 → 交付）的工具链与实测约束集。
适用于以“参考图锁角色 + 多镜拼装 + 音画同步”为特征的短视频生产。

所有结论均在单机环境实测；每条标注证据档：**实测**（有可复核输出）／**现场记录**（真实发生但触发条件未完全复现）／**机制推断**（由已知机制推出，未直接验证）。

## 这份文档面向谁、不面向什么

本仓收录的是**方法与判据**，不是可以直接复制粘贴的成品配置。

- **面向**：遇到同类问题的读者——先看懂问题为什么发生、判据怎么定，再把方法放到自己的环境里。
- **不面向**：照搬本仓的参数与结构。文档里出现的具体数值（阈值、条数、型号、步数、时长）**均为某一环境下的一次取值**，不是推荐默认值；换成不同硬件、不同模型版本时结论可能不适用。
- **判据优先于参数**：每条结论都写了“怎么判断它成立／不成立”。参数可以变，判据不变。
- **证据分级**：文中结论标注「实测」（有可复核输出）／「现场记录」（真实发生但触发条件未完全复现）／「机制推断」（由已知机制推出，未直接验证）。三档不混写；标为推断的内容不得在后续引用中被升级为确定结论。

## 它解决什么

单机条件下，AI 视频生成的难点不在于“能不能出片”，而在于四个可重复失败的地方：

1. **角色不一致**——同一角色在不同镜头里变成不同的人；
2. **空间不一致**——参考图是白底立绘时，场景全靠模型即兴发挥，镜头之间房间布局不同；
3. **时序不稳定**——动作做到一半突变、道具状态前后矛皾；
4. **音画不同步**——语音与口型、音效与动作节拍对不上。

本仓把每个环节的**可量化验收判据**与对应的处理办法固定下来。

## 核心方法：两步法首帧锚定

**解决的问题**：多镜拼装时角色与空间漂移。

**示例判据**：相邻镜头是否同角色、同服装、同空间、姿态连续（逐镜抽帧后交叉核对）。

**原因**：单次生成中模型同时决定“长什么样”与“怎么动”，两者互相干扰；每镜都从文本重新描述，等价于每镜重新掷一次骰子。

**解决方案**：把“长什么样”与“怎么动”拆成两次生成——

```
1) 静帧模式出“站姿/坐姿底帧”（固定 seed）
2) 取底帧作 start-image，再跑动作，并保持同一参考图
3) 跨镜时：取上一镜末帧（向前偏移 0.2-0.4 s，避开模型末帧常现的模糊/冻结）作下一镜首帧
```

实测效果：角色、服装、空间、姿态跨镜保持一致（**实测**）。

## 已固定的约束（结论）

| 解决的问题 | 示例判据 | 原因 | 解决方案 |
| --- | --- | --- | --- |
| 文本提示写对但动作几乎不动 | 第 3 帧后画面近乎停滞 | 提示词格式不符合官方 FL2VA 格式 | 按 `docs/h3-prompt-format.md` 写：首行对齐指令 ＋ 正文 350-500 词（**实测**） |
| 负向提示词不生效 | 写入的否定词对结果无影响 | 模型为 CFG-distilled，全链路无负向分支 | 不写否定句，改用正向描述目标状态（**实测**） |
| “沿轴旋转”类动作会把肢体重画 | 手背与手心被整体替换而非转动 | 模型无体积/解剖约束，旋转对其等价于“重画一个看起来对的视图” | 不写旋转，直接写末态；或用机位变化／拆镜替代（**实测**） |
| 把整段过程塞进一镜→内容崩坏 | 单镜内道具出现不可逆矛盾 | 单镜内可用生成预算有限，阶段越多越容易失控 | 一镜一事：一个镜头只做一个拍子；必要时用插入镜（空镜/道具特写）承担时间流逝（**实测**） |
| 配音后口型对不上 | 语音与口型时间轴错位 | 外部音轨驱动模式下官方不保证精确唇同步；帧率非 24 时错位更明显 | 帧率固定 24；对精度要求高的镜头改用唇形重绘（**实测＋现场记录**） |
| 低显存下长视频 OOM | 高分辨率长帧数时显存/页面文件撞顶 | 权重与文本编码器同时驻留，超过可用显存 | 换低位宽文本编码器（如 NVFP4）＋ 固定页面文件；实测 192 帧可完成（**实测**） |
| 多人同框串脸 | 两个角色面部特征互相污染 | 参考图叠加时人脸特征在 latent 空间互相干扰 | 不同框：正反打分切；或斜角/一前一后站位，并显式声明“两张脸属于两个不同的人”（**现场记录**） |

## 工具

| `style-metrics.py` | 画风漂移量化（颜色数 / 亮度梯度） |
